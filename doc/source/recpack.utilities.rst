Utility modules
===============

RecPack's utility modules provide shared matrix manipulation, conversion,
batching, sampling, arithmetic, and identifier-mapping helpers. They are useful
when extending RecPack with new algorithms, metrics, or preprocessing logic.

they are used to support custom algorithm implementations.
